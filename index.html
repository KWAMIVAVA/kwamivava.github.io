🛠️ soulmask-desktop - Keep Your Soulmask Files Organized

A friendly, local helper for Windows and macOS that finds your Soulmask data paths, keeps config files tidy, cleans up export caches, and opens your export folders without any guesswork.

⬇️ Download soulmask-desktop

Visit this link to download the application. No account, no payment, no technical knowledge needed.

🧭 What soulmask-desktop Does

Soulmask keeps a lot of information scattered across your computer. Save data lives in one folder, configuration files live in another, cached exports pile up somewhere else, and the folders you actually want to look at are buried several levels deep. soulmask-desktop is a small desktop program that keeps all of that in one simple window.

Instead of hunting through hidden folders, you open the app, and it shows you exactly where your Soulmask data lives. You can open any of those locations with a single click, copy a path to share with a friend or a support thread, and clear out cached export files when they start taking up too much space. Everything happens on your own machine.

📍 Data path finder

Automatically detects the folders Soulmask uses for saves, settings and local data, then shows you the full path in plain text.

📝 Config file shortcuts

Jump straight to the configuration files that Soulmask reads at startup, without digging through AppData or hidden library folders.

🧹 Export cache cleanup

See how much space cached export files are using, then clear them safely when you no longer need them. Your main data is left alone.

📂 Export folder launcher

Open your export destination folder instantly, so you can move or back up files without memorizing where they landed.

🚀 Getting Started

You do not need to install anything complicated, and you do not need to type commands anywhere. The whole process is: download, open, look around. Three simple ideas will get you through it.

  • Everything is local. soulmask-desktop runs on your own computer. It does not need an internet connection to do its job and does not upload your files anywhere.
  • It only looks, unless you tell it to act. Finding a path is safe and read-only. Deleting a cache or opening a folder only happens when you click the matching button.
  • Nothing is permanent. You can close the app at any time. If you are unsure about a button, close the window, reopen it later and nothing will have changed.

🖥️ Before You Begin

soulmask-desktop is designed for everyday Windows computers and also includes a macOS helper for the same folders. To get a smooth experience, check these simple points first.

  • Windows 10 or Windows 11 on a normal desktop or laptop. The app is built for standard 64-bit systems.
  • Around 100 MB of free disk space. That is plenty for the program itself plus a little room for temporary files.
  • Your own user account. Using the account you normally sign in with avoids permission messages. Avoid running the app as a different user unless you know you need to.
  • Soulmask already has data on the machine. If the game has never been launched, there may be nothing to find yet, which is completely normal.

⚙️ First-Time Setup

The first time you open soulmask-desktop, it asks a few quick questions so it can point at the right folders. This usually takes under a minute.

  1. Let it scan. Press the scan or detect button and wait a few seconds. The app looks for known Soulmask locations on your drive.
  2. Confirm the detected paths. If the app shows a folder that matches where your Soulmask files really are, accept it. If it looks wrong, use the browse button to pick the correct folder yourself.
  3. Choose an export folder. This is simply the place where the app will send you when you want to look at exported files. Any empty folder you can find will do.
  4. Save your settings. Once saved, soulmask-desktop remembers your choices, so you only do this once.

If a folder cannot be found, it is usually because Soulmask has not been started on this computer yet. Launch the game once, close it, then run the scan again.

📁 Working With Export Folders

Export folders are the most-used part of the app for most people. They are the folders that hold files the game produces for you, such as copies of your settings or saved data you want to keep somewhere else.

Inside soulmask-desktop you will find a button that opens the export folder directly in your normal file browser. From there you can drag files out, copy them to a USB stick, or zip them up to share. Because the app opens the same folder your system uses, nothing is duplicated or moved behind your back.

The cache area works the same way, except it is usually safe to empty. Cached export files are temporary copies the game creates while working. Clearing them frees up space without touching your actual configuration or saves. If you are ever unsure, open the folder first, look at the file dates, and only clear files you recognize as temporary.

🛠️ Troubleshooting

The app does not open when I double-click it

Wait ten seconds and try again. If nothing appears, right-click the file and choose "Run as administrator" once. On Windows 11, check the notification area in the bottom-right corner of the screen in case a security prompt is waiting for an answer.

Windows says the file is not commonly downloaded

This is a standard message for smaller independent programs. Open it by selecting "More info" and then "Run anyway". If your browser kept the file in a downloads list instead of saving it, use the option to keep the file first, then open it from your Downloads folder.

No folders are found during the scan

Start Soulmask once, let it load to the main menu, then close it. Reopen soulmask-desktop and run the scan again. If it still finds nothing, choose the browse button and point at your Soulmask folder manually.

A folder opens but it looks empty

Some folders are hidden by default in Windows. In your file browser, open the View menu and enable hidden items, then refresh the window. The app itself always shows the real location, even when Windows hides it.

Permission denied when saving settings

Make sure you are signed in with your normal account and that you are not pointing the app at a protected system folder. Choosing a folder inside your own user area, such as Documents, solves this almost every time.

💡 Tips for a Smooth Experience

  • Keep the program file in a permanent folder rather than a temporary one, so your saved settings stay associated with it.
  • Copy paths with the app's copy button instead of retyping them. Long folder paths are easy to mistype.
  • Back up your config files before editing anything by hand. Copy them into a folder with today's date in the name.
  • Check for a newer release from the same download page every few months. Newer versions usually detect more folder layouts automatically.
  • If you move Soulmask to a different drive, reopen the app and run the scan again so it can update its saved paths.

Privacy and Local Storage

All of your Soulmask data stays on your computer. soulmask-desktop reads folder locations, displays them, and performs the actions you click. It stores your chosen paths in a small settings file on the same machine so it does not have to ask again. Nothing is uploaded, shared, or collected.
